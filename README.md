# blog-pogol

Source for Steve Powell's personal blog at [pogol.net](https://pogol.net). It is a [Quartz 4](https://quartz.jzhao.xyz/) static site, written as Obsidian-flavoured markdown and published by Netlify.

Steve is co-founder of [Causal Map Ltd](https://causalmap.app) and writes here about evaluation, causal mapping and applied social research. The blog is separate from the company knowledge garden at [garden.causalmap.app](https://garden.causalmap.app).

## How it works

- Posts are markdown files in `content/`.
- Files in `quartz/static/` are copied as-is to `public/static/` and served at `/static/...`.
- `public/` is the build output. It is gitignored and regenerated by Netlify on each push.
- Netlify runs `npx quartz build` and serves the result. There is no `netlify.toml`; build settings are in the Netlify dashboard.

## Editing

1. Add or edit markdown in `content/`.
2. Put any files that should be served unchanged in `quartz/static/`.
3. `git push`. Netlify builds and deploys.

To preview locally, follow the [Quartz docs](https://quartz.jzhao.xyz/): `npx quartz build --serve`.

## Config

- `quartz.config.ts` holds the Quartz config: plugins, theme and `baseUrl`.
- `readme-howto-quartz.txt` has working notes on the Quartz setup.
