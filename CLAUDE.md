# blog-pogol

Quartz 4 static site, hosted on Netlify.

## How it works

- Content lives in `content/` as Obsidian-flavored markdown
- `quartz/static/` holds static assets copied as-is to `public/static/` during build
- `public/` is gitignored (build output, regenerated by Netlify)
- Netlify runs `npx quartz build` on push and serves the output

## Workflow

1. Edit markdown in `content/`
2. For static files to serve as-is: put in `quartz/static/` (served at `/static/...`)
3. `git push` — Netlify builds and deploys automatically

## Config

- `quartz.config.ts` — main Quartz config (plugins, theme, baseUrl)
- No `netlify.toml` — Netlify build settings configured via dashboard

## Notes

- `baseUrl` in `quartz.config.ts` should be `pogol.net` (currently still set to the Quartz default `quartz.jzhao.xyz`)
